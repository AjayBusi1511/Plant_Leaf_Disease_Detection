🌿 Plant Disease Detection Using Deep Learning

A deep learning-based web application that detects plant diseases from leaf images and provides disease information, prevention methods, and treatment recommendations. The model is trained using the PlantVillage dataset and leverages MobileNetV2 transfer learning for accurate and efficient disease classification.

🚀 Features
Detects diseases from uploaded plant leaf images
Supports 38 plant disease and healthy classes
Achieves approximately 96% classification accuracy
Uses MobileNetV2 transfer learning for improved performance
Provides disease description, prevention, and treatment suggestions
Grad-CAM visualization for model explainability
User-friendly Streamlit interface
